## TikTok美区IP的三层区别：机房IP、原生IP、双ISP家宽

TikTok 判断一个账号，看四样东西：IP 归属地、IP 类型、设备指纹、行为模式。四样里 IP 类型触发风控最频繁，也是最容易在买服务器这一步就搞错的。

机房 IP 由数据中心批量分配，正常美国居民不会用这种网络刷手机，行为本身就是异常信号。住宅 IP 由本地运营商分配给真实住宅地址，WHOIS 显示 Private Customer，在风控眼里就是一个普通美国用户在家上网。

原生 IP 和家宽 IP 是两件事。原生指 IP 的注册地和服务器所在国一致，美国节点配美国 IP 段，这叫原生。家宽指这个 IP 确实从当地 ISP 的家庭宽带线路出来。两者都重要，但对 TikTok 的风控来说，家宽属性更接近真人。有些商家把"原生"当卖点，实际上只是机房 IP 换了注册地，家宽属性一点没有。

双 ISP 是这几年针对风控做出来的折中方案：同一个 IP 同时挂在两个真实 ISP 名下，查询结果里能看到两个运营商，信任度比单 ISP 高一档。它不等于真家宽，但成本比真家宽低得多。六六云官网就把这两类分开卖，双 ISP 那几款月付 50 元起，"美国家宽IP-AT&T"单列一款，200Mbps 带宽、2TB 流量、月付 200 元，本次显示暂时缺货。真家宽的价格是双 ISP 的四倍，这个差价也说明双 ISP 是在成本和"像真人"之间取的一个位置。

地区必须对上。美区、英区、东南亚的推荐池是分开的，用香港 IP 跑美区，账号定位和推流池都会偏，数据差一截不是内容的问题。

IP 是门槛，不是全部。设备指纹、操作行为、内容质量同样影响数据表现，换了干净的住宅 IP，内容不行、行为异常，照样起不来。反过来说，IP 这一关不过，后面的优化都是在漏水的桶里加水。

## 带宽和流量怎么算才不踩坑

先给结论：这几款套餐的带宽，对单账号直播全都是过剩的，真正拉开差距的是 IP 段和回程线路，不是标称带宽。

TikTok 官方的建议是高质量直播最低 2.5Mbps，手机直播最低 3Mbps、建议 5Mbps 以上，OBS 电脑推流至少 5Mbps、1080p 建议 10Mbps 以上，多机位或 4K 才需要 30Mbps 以上。对照一下表里的数字，200Mbps 的 9929 和 CN2 GIA，按"推流不超过标称带宽一半"的经验值算，也留着 100Mbps 的余量，够跑十几路 1080p。1Gbps 那几款更不用说。

带宽不是瓶颈，流量才是容易算错的地方。一小时直播推流大约消耗 1 到 2GB，取决于码率。每天播四小时就是 4 到 8GB，一个月 120 到 240GB。再加上养号刷视频、上传素材、日常远程操作，一个月 500GB 打不住。

按这个口径倒推：820GB 的 CN2 GIA，扣掉日常消耗，留给直播的大约 600GB，按每天直播三小时算能撑两个多月，单账号够用但它本来就不是给主账号准备的。1TB 是主流起点，一天播四五小时、加日常操作，一个月下来还剩两三成余量。2TB 那档是给双账号、或者一天播六七小时的重度使用者准备的。超流量一般是限速，不限速也会很难受，一开始就选够比事后补便宜。
